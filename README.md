# ShopNest Store – Power BI Executive Sales & Operations Dashboard

## 📊 Project Overview
This project presents an end-to-end Sales & Operations dashboard built using Power BI.

The dashboard provides insights into sales performance, delivery efficiency, customer behavior, seasonal trends, and product ratings.

All data cleaning, transformation, modeling, and analysis were performed directly inside Power BI.

---

## 🔍 Business Questions Solved

1. Top 10 Product Categories by Total Sales  
2. Delayed Orders Analysis  
3. Monthly Comparison of Delayed vs On-Time Orders (Drill-through Enabled)  
4. Payment Method Analysis  
5. Top 10 Highest-Rated Products  
6. Bottom 10 Lowest-Rated Products  
7. State-wise Sales Analysis  
8. Seasonal Sales Pattern (Quarterly)  
9. Yearly Revenue Trend  

---

## 🛠 Tools & Technologies Used

- Power BI
- DAX (Data Analysis Expressions)
- Data Modeling
- Drill-through & Cross-report Analysis
- Interactive Visualizations

---

## 📂 Data Preparation & Cleaning

✔ Data cleaning performed inside Power BI  
✔ Relationships built using Star Schema model  
✔ Calculated Measures created using DAX  
✔ Delivery Status logic implemented  
✔ Rating aggregation handled properly  
✔ Top/Bottom N filtering applied dynamically  

---

## 📈 Key Dashboard Features

- Interactive slicers (Year, Product Category, State)
- Drill-through page for monthly delivery analysis
- KPI Cards for revenue, orders, rating & customers
- Seasonal trend visualization
- Revenue growth analysis
- State-level performance tracking
